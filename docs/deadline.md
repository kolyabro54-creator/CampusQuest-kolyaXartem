# [CQ5 / CQ6]

## Зачем нужна
[Интерфейс для ввода разгадки и мгновенная обратная связь (верно/неверно) с начислением очков.]

## Пользовательский сценарий
1. Игрок вводит ответ в поле и нажимает «Проверить».
2. Система сравнивает ответ с правильным вариантом.
3. Если верно — появляется «Верно!» и начисляются баллы.
4. Если нет — появляется «Попробуй еще», поле снова активно.


## Критерий готовности
- Кнопка «Проверить» неактивна при пустом поле.
- Проверка не зависит от регистра (заглавные/строчные буквы).
- При верном ответе виден успех и начислены очки.


## Риск или вопрос
- Риск: двойной клик по кнопке отправит запрос дважды. *Решение: блокировать кнопку во время проверки.*
- Вопрос: нужна ли поддержка синонимов (несколько правильных вариантов ответа)?
